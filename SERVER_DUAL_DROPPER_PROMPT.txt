四、与本地完全相同的大小算法
对每个 model_points_world_artifact 中的米制 XYZ 顶点，用 float64 计算：
  origin = points.mean(axis=0)
  centered = points - origin
  covariance = centered.T @ centered / len(points)
  eigenvalues, axes = numpy.linalg.eigh(covariance)
  axes = axes[:, numpy.argsort(eigenvalues)[::-1]]
  projected = centered @ axes
  bounds = numpy.quantile(projected, [0.01, 0.99], axis=0)
  dimensions_m = bounds[1] - bounds[0]
  volume_m3 = float(numpy.prod(dimensions_m))
这是恢复尺度后的稳健 PCA 包围盒体积代理，不是液体容量，也不能替换为原始 canonical scale 比较。至少10个有效模型点，dimensions 必须为正。
较小 volume 对应 small_id，较大对应 large_id；要求 large/small >= 请求的 minimum_dropper_size_ratio（缺省1.10，必须有限且>1）。两者接近、任一实例缺失/退化或重复重建同一对象时，明确返回失败原因并保留调试产物，不根据颜色/位置/名称猜测。
result.json 增加：
  "dropper_size_ranking": {
    "method": "pca_obb_volume_m3_q01_q99",
    "small_id": "dropper_a 或 dropper_b",
    "large_id": "另一个实例ID",
    "large_to_small_ratio": 数值,
    "minimum_ratio": 1.10,
    "models": {
      "dropper_a": {"dimensions_m": [dx,dy,dz], "volume_m3": 数值},
      "dropper_b": {"dimensions_m": [dx,dy,dz], "volume_m3": 数值}
    }
